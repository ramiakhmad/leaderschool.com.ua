# Odesa Leaders School

Адаптивний україномовний сайт приватної школи в Одесі. Містить сім сторінок, три варіанти оформлення, фотогалерею, фільтри новин і форми звернень.

[Відкрити розгорнутий сайт](https://odesa-leaders-school.rami-akhmad.chatgpt.site/?design=bright)

## Локальний запуск

Потрібен Python 3. З кореня репозиторію запустіть:

```bash
python -m http.server 8000
```

Відкрийте [http://localhost:8000](http://localhost:8000). Сайт використовує HTML, CSS та JavaScript без встановлення залежностей або збірки.

## Структура

- `index.html` — головна сторінка.
- `about.html`, `programs.html`, `school-life.html`, `news.html`, `admissions.html`, `contacts.html` — внутрішні сторінки.
- `styles.css`, `site.js` — спільні стилі, перемикач оформлення, меню та галерея.
- `*-reference.css`, `*-reference.js` — стилі й поведінка окремих сторінок.
- `assets/` — логотип, персонаж і фотографії.

## Публікація

Розмістіть файли зі збереженням структури каталогів на статичному хостингу. Точкою входу є `index.html`. Для GitHub Pages, якщо функція доступна, оберіть **Settings → Pages → Deploy from a branch**, основну гілку та каталог `/ (root)`.

Форми готують чернетки листів через `mailto:`. Відправлення завершується у поштовому застосунку відвідувача. Автоматична розсилка та серверний збір заявок не налаштовані.
